│ TABLE: health_score_snapshots                                            │
├───────────────────┬──────────────┬──────────────────────────────────────┤
│ FIELD             │ TYPE         │ SOURCE                               │
├───────────────────┼──────────────┼──────────────────────────────────────┤
│ id                │ UUID         │ AUTO-GENERATED (database)            │
│ user_id           │ UUID         │ FOREIGN KEY → users                  │
│ overall_score     │ INTEGER      │ 🖥️ BACKEND COMPUTED (formula)        │
│ calculated_at     │ TIMESTAMP    │ AUTO-GENERATED (database)            │
└───────────────────┴──────────────┴──────────────────────────────────────┘

BACKEND CALCULATION FORMULA:
overall_score = weighted average of:
  - Cash Flow Score (33%): based on savings_rate from existing data
  - Debt Score (33%): based on outstanding_debts debt-to-income ratio
  - Goals Score (33%): average progress across all goals
  
USES EXISTING DATA:
  - monthly_income, monthly_expenses, savings_rate
  - outstanding_debts (balance, monthly_payment, interest_rate)
  - goals (current_amount, target_amount, deadline)

How Adaptive Monitoring Works (AI-Driven):
Your backend monitoring service should:

Automatically track changes by comparing current data vs. historical snapshots

AI detects patterns like:

Spending suddenly increased 40% this month
You're falling behind on a goal deadline
Investment account value dropped significantly
Debt interest is consuming more of your budget
Savings rate decreased
AI generates contextual alerts without user configuration:

"Your discretionary spending is 35% higher than usual this month"
"At your current pace, you'll miss your Emergency Fund goal by 3 months"
"Your portfolio volatility increased - consider rebalancing"
